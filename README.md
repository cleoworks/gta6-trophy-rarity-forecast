Forecasts, for every GTA VI trophy on PS5, the percent of Exophase-tracked players who will have earned it at 2026-11-26T00:00:00Z, as five quantiles (5/25/50/75/95%) per trophy, from the page reads before the case checkpoint. Model: earners-over-tracked split, log-time fit on distinct page states only (last 24h window), group-shrunk slopes with a floor at zero for the slowest groups, per-group prior caps, story-chain monotonicity, and a wide downward-only spread for the trophy sitting at 100%.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
